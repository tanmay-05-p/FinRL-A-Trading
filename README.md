## 📊 Where the Technology Fits

Deep reinforcement learning is a method where a computer program learns by receiving feedback. In trading terms, the program makes a decision, sees what happened as a result, and adjusts its behavior. Repeated thousands of times on historical data, this process produces a strategy that has been shaped by real market patterns.

FinRL-A-Trading packages several well-established versions of this idea so you can compare them:

- **A2C** learns from many simulated scenarios at once and tends to be steady and reliable.
- **DDPG** works well when decisions involve fine-grained amounts, such as how much of a portfolio to allocate to one holding versus another.

By running both on the same data and comparing results, you get an honest view of which approach suits which situation. That comparison is the heart of what this application was built to make easy.
